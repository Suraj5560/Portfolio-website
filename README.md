# Portfolio-website
A clean and responsive personal portfolio website built using React + Vite, designed for a professional Cost Management Accountant (CMA) . This project showcases personal details, achievements, services, and contact information in a modern and user-friendly layout.


✨ Features

Responsive design for all screen sizes

Smooth navigation with React Router

Home section with profile image and greeting

About section highlighting achievements and experience

Services section with tab-based service listing

Contact section with email, phone, WhatsApp, and social links

Modern UI with glassmorphism / neumorphism styling

🛠️ Tech Stack

React

Vite

JavaScript

HTML5

CSS3
